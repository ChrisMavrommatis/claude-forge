# templates

File shapes the skill writes into `.plans`. Read the relevant one only when creating
that file — not on every run.

| Template | Used for |
| -------- | -------- |
| [scope.md](scope.md) | The flat scope file (`.plans/<name>.md`) — one per feature. |

The file leads with a **Status** block (the at-a-glance view — `🎯 Ask`, `🧩 Build`,
`🕳️ Unknowns`, `☑️ Decided`, `⚠️ Risks`, `📏 Size`) and keeps the fuller record below it.
